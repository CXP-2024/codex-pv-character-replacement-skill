# 检查、返修与交付

## 检查真实画面

先定位最早错误层：`原片 → 起点图 → H3 raw → 选帧/曝光 → 合成 → 可选超分 → 编码文件`。raw 已正确就修下游。短返修段检查全部变化帧，连同前后接缝；长片保存覆盖记录。全画面、目标局部和邻接轮廓都要看，不能仅看首中尾。

| 项目 | 重点 |
|---|---|
| 身份/画风 | 眼睛、刘海、发量、饰品、头身比、身高、裙长和同一件衣服；正侧背视一致 |
| 动作 | 睁眼与口型、手指/手腕接触、拍打相位、点脚落地、重心；有风的头发衣服确实运动 |
| 构图/遮挡 | 源画面位置、尺度、裁切；手指不被 matte 截断，人物不穿过树干或前景 |
| 光效/背景 | 地面、树木和光斑不跳；投影、遮盖→显现、曝光与原片时序相符 |
| 接缝 | 人物设计、姿态和明暗不重置；重叠只选一份，原本的切镜/白闪保留 |

差值和跟踪用于定位，平均低分不能排除单眼、细黑条或恒定接缝；独立查看遮罩内外和四边。源身份与目标不同，不追求整图像素差为零。用正常速度检查观感；无法播放时记录连续帧检查范围，不声称已观看播放。技术通过、人工观察和用户认可分开记。

## 平色修复与光照

本类平色 PV 的白色交替碎块/鳞片纹不应当作细节保留。按眼睛→眼周/额头发际→头发→面颈肩手→服饰及边缘检查。统一局部平色，保护真实轮廓、抗锯齿和较大连续阴影边界；真实大块反光、边缘光与投影另行保留。不要全局模糊或抹去明暗层次。需要非生成式局部清理时，可用环境中的 `cel-flat-color-cleanup`。

若 raw 人物曝光突变，先从前面的可靠 H3 状态续跑并约束原光照。不要用后置硬人物遮罩把整个人压成剪影来掩盖失败；用户要撤掉遮罩时也检查底层 raw，不能撤掉后留下原来的闪亮跳帧。

## 文字、Logo 与原片复用

每段标明歌词、水印、标题、staff、环境文字的 keep/erase/replace。按项目要求去除；一旦要求全片无歌词/水印，原片直用段也不能漏检。清理范围覆盖移动边界和消失尾巴，不靠 OCR 一次扫描或初始矩形免检。

保留动态原片时只修需去字的区域，检查文字跨人物/衣物的部分。去字失败而必须改用 H3 时，仍按单镜头连续链处理。不能为了无字把动态片段换成静止封面，除非用户明确选择这种播片方案。

标题/署名用独立透明图层：相同 Logo 优先提取或复用原字形，小号文字优先实际字体排版。逐字核对、检查真实 RGBA、位置、大小、斜度、投影、出入场与遮挡。未知字体只说样式匹配，不能声称鉴定了原字体。开篇标题需跟随原动效，不能只贴静态最终图；在最终尺寸叠字，字层修改不重跑正确的 H3。

## 回填与交付

1. 冻结当前选用基线和修复范围。逐帧台账记录源帧/PTS、实际 PNG、模型索引、hash、图层及版本；每个源时刻有唯一有效选择，旧失败候选不自动回填。
2. 修复无损素材后，验证范围外资产/hash 或像素不变。一次只升级所需下游；原生直用画面不先降清再超分，超分按当前约定执行，不能用插值缩放冒充模型超分。
3. 从直接解码 PNG/原生素材制作成片，保留无损序列供最终母版。预览采用用户设备兼容编码；本次经验为 MP4/H.264 yuv420p + MP3 音频，不把它强制成所有项目默认。最终无损交付另按约定导出 PNG/FFV1、PCM/FLAC 等。
4. 保留约定的原音轨与源时间。加 BGM 与替换人声分开，不能误删对白；裁切、变速及字幕时间只变换一次，核对起点、拼接和尾句。音频不覆盖全片时先明确剩余段处理。
5. 核对真实编码、尺寸、精确 fps/PTS、帧数、时长和音轨，全文件解码。回读实际输出并核对本次修复帧、接缝和文字；编码正常不等于美术通过。
6. 输出原片/新版并排帧号对比与纯成片，报告检查范围和实存差异。交付完整后再推进最新版本指针；保留前版、锚点、采用 H3 PNG、链记录与脚本。

具体角色表、原片、完整日志、私有路径、服务地址和素材留在项目；skill 只保存可迁移的方法。
