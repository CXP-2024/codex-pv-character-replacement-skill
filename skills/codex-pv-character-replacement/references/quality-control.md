# 帧级验收：差值定位，视觉判断

保存基准版本、源/输出帧映射、预期变化事件、允许修改的空间和时间范围。检查实际装配并回读的帧，不只看锚帧。

## 四种独立判断

| 判断 | 证据 | 常见假通过 |
|---|---|---|
| 身份与结构 | 放大眼、脸、发饰、嘴及完整轮廓；对照认可身份与原表演 | 眼清楚但眼眶歪，嘴对了但脸被贴变形 |
| 动作与曝光 | 源/新版事件表、姿态和原速并排预览 | 顺序对但太快；事件对但转向或幅度错 |
| 合成与背景 | 图层、matte、外框、空背景及边缘差值 | 人物不变，但保护区内部残留旧黑影 |
| 交付完整性 | 范围外无损比较、解码/PTS、音轨与字幕 | 完整解码就宣称美术通过 |

## 查看范围

- 短返修段查看全部帧，包括进入/退出的可信上下文；长段同绘稿可用代表帧，但所有实际变化帧、遮挡变化帧及修补边界需放大。源为静止而输出变化的帧不能跳过。
- 用户指出帧强制纳入，与阈值无关。退回未解释清楚前，自动 PASS 不能撤销它。
- 全屏看画风、运镜、光影和层级；原生小脸以最近邻放大看结构，再按正常播放尺寸判断清晰度。缩略图拼版仅作索引，不作饰品/眼嘴验收证据。
- 检查完整轮廓：头顶、刘海与眼交界、耳后、下巴、领口、发丝间隙、手臂、裙摆、前景遮挡和画框底边。眼鼻本身正确不代表周围没被破坏。
- 生成阶段看 raw，选帧后看曝光映射，合成后看接缝，SR后和最终编码后再看实图。未看过的范围写“未检查”，不自动填全段通过。

## 差值怎么测，漏检怎么查

1. **解耦运动。** 从静态背景估相机，保留原始和运动补偿后的比较。错误配准会制造或隐藏变化；检查跟踪质量与实图，不能非刚性扭脸来压低残差。
2. **分区测量。** 每人眼/嘴/头饰/轮廓/身体、独立背景与边界环分别统计。ROI混入前景会把动作当背景闪烁；宽人物保护区也可能藏着坏背景。
3. **同时看时间和空间。** 保存固定显示量程的绝对差值热图，与相邻帧、可信同姿态帧、底片/供体对照。只看相邻帧会漏一直存在的接缝；全帧平均会稀释窄黑条、单眼和几像素头饰缺失。
4. **不止平均数。** 辅助记录局部高分位差、变化面积、最大连通区域及位置；细长连通带优先查拼接边。配准静态层比较轮廓位移，皮肤与虹膜分别测色。阈值据真实噪声、压缩和场景设定，不使用跨项目固定美术阈值。
5. **独立验证遮罩。** 在正常帧显示覆盖，检查遮罩内、外、边缘两侧，包含保护区里的空背景、外裁切四边和旧人物运动包络。不能用生产遮罩排除全部可疑区域，再用剩余区域低MAD证明修好了。

曝光复用在合成/SR前验证同一静止层像素一致；背景、遮挡及相机可继续变化。SR邻域依赖和有损编码可能产生小差值，区分检查层级；不把最终微小误差当动作，也不容许明显跳变借此免责。

## 每类问题的退出条件

| 问题 | 修复后必须能展示 |
|---|---|
| 眼/脸变形、瞳色错误 | 所有相关姿势的完整小脸及邻接头发；身份配色一致，源视线/表情保留 |
| 嘴漂移/过锐/漏微张 | 口型事件逐项对应；头部坐标稳定，实际尺寸下无贴片感 |
| 头饰裁掉/黑边 | 全运动包络与框边都覆盖；中间帧不被matte或外框截断 |
| 背景闪烁/黑影 | 差值图和正常帧均无异常接缝；墙线、粒子与真实光照连续 |
| 动作快慢不符/定格颤动 | 源事件、模型选帧、曝光长度对应；静止者无额外运动 |
| 前中后画风突变 | 两侧定格、动作和接缝同一画风与照明，不以溶解制造双像 |
| 修补伤及其它位置 | 无损允许范围外像素一致；有损交付另做回读而不宣称bit-exact |

交付文件全段解码，核对尺寸、精确fps/PTS、帧数及首尾；音轨按实际切点/加速规则检查，流复制时可核对音频包哈希。字幕核对采用版本及改动条目。

最后以正常速度看完整镜头及接缝；慢放/差值辅助定位，不能替代正常观感。不能播放时说明限制，用连续帧覆盖提供有限证据，不声称已观看播放。
