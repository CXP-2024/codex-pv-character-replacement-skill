# 失败案例索引

这些是实际制作遇到的模式，解决方法有适用前提，不是统一自动修复规则。

| 症状 | 最早定位 | 处理 | 不能拿什么当通过 |
|---|---|---|---|
| v3与旧人设几乎一样 | 旧AI图被当编辑底图 | 原作图作Image1、AI身份作Image2、原片CG作画风锚 | prompt写了“原作风” |
| 头发油亮细丝过多 | 身份锚和关键帧上游 | 先校准哑光/发量/块状高光，再传播身份版本 | 后期去饱和 |
| 呆毛变头顶圆环 | 身份文字和剪影 | 明确发根/自由末端，删除悬浮闭环描述，重做相关锚 | 正面立绘看着像 |
| Q版首尾粗线、中间细线 | 视频中段 | 原片同帧线宽/颜色/白边，补阶段锚和曝光 | 两端正确 |
| 发饰左右瞬移 | 跨镜关键帧/映射 | 用画面左右定位，扩大转场区重跑并全流程回填 | 单镜各自好看 |
| 背景男主变脸 | 整帧生图的保护不够 | 原片作底图、保护角色职责，必要时可靠分层保留 | “不要改男主”一句话 |
| 转场突然闭眼/放大 | 模型提前改变阶段 | 原视频完整转场上下文，按阶段锚分段，检查真实事件帧 | copy_check PASS |
| 跑步像漂移 | 只有平移、没腿部节拍 | 检查脚落点与重心，重做连续跑姿，必要时角色层定位 | 位移方向正确 |
| 多层名字卡变静图 | 静态底图替代动画 | Ref2VA动态画面层，文字另叠 | 字体效果好 |
| 旧Logo在淡出后返影 | H3残字尾部超出覆盖窗口 | 查原片/H3/合成三层，清完整残留区间 | 源片消失帧 |
| 标题边缘破烂 | alpha资产、颜色mask、缩放 | 看透明图边缘和实际合成，重做清晰资产，禁旧色挖新字 | 只检查中央字 |
| 小脸超分更吓人 | H3原生像素不足 | 高分辨率局部输入生成、连续化、局部SR回填 | 换锐化SR |
| 6帧重叠双眼/双发丝 | 两段姿态不一致 | 可信端点短FL桥或重新统一锚，不默认溶解 | MAD变低 |
| H3卡在0/20且很慢 | 专用显存/共享溢出/竞争 | 单GPU、卸载、看门狗、受控一次重试 | 没报OOM |
| 全部hash正确仍跑旧风格 | 当前有效批准或选用清单过时 | 校验批准内容+身份版本依赖，撤回使旧输出失效 | complete状态 |
| raw已生成但任务failed | CPU QC、父ID、编码失败 | 检查raw完整后只恢复后处理，保留错误记录 | 盲目再跑H3 |
| 显示无角色却冒出人 | 无关定妆照/公共prompt污染 | 无cast任务不放身份图，只给当前场景锚 | 原任务名称 |
| 文字去除只在几帧有效 | 移动bbox或范围漏尾 | 全范围去字清单+跟踪区间+最后编码回读 | OCR没发现 |
| 最终像素清晰但角色不符 | 原始画面就错 | 回上游重做，不靠SR改身份 | 1920×1080标签 |
| 旧版重回长片 | 装配靠glob/mtime | 帧级selected台账，局部范围外对照最新母版 | 文件名含final |
| 群怪替换多出人数 | 生成式群像近似 | 每实例/遮挡锚清单，密集检查；否则明确近似差异 | 所有脸像目标 |
| 浴室套上战斗服 | 身份和衣装职责混写 | 保留场景服装覆盖，只换授权身份 | 服装来自定妆照 |
| 只修一帧导致后续错位 | 删除帧破坏时间轴 | 用户“移除坏帧”先理解为替换/重新曝光，保持原时长，除非明确要改剪辑 | 删掉文件后能播放 |
| 多轮修图后出现油纹碎片 | 上一版生成图被反复编辑 | 从原片对应帧重新直出，身份参考与原表演分开 | 面部已经像目标 |
| 头动、衣服冻结或两个头 | 头部贴图/非等比配准 | 短H3完整人物动作，按原绘稿曝光选帧 | 头部中心对齐 |
| 抠图缺手臂、发梢带暗阶梯 | 人物matte与旧背景污染 | 全人物检查、修整遮罩和边缘颜色、核对前景遮挡 | 脸部放大图通过 |
| 侧脸嘴是暗块/尖刺 | 旧嘴未清净或ROI越过面部边界 | 各姿势分别恢复皮肤与背景，源嘴形及曝光定标 | 音频长度一致 |
| 背景颤动、定格头饰漂移 | 整帧自由生成/逐帧重抠 | 测源相机、复用可信绘稿及matte，保留真实运动 | 平滑后MAD低 |

这些对话与分层案例的适用前提、操作和校验见 [dialogue-and-layers.md](dialogue-and-layers.md)。

## 累积修复原则

不要机械叠加所有历史补丁。维护当前选择和废弃原因，重做跨越补丁的区间时复核覆盖关系。一次只改一个已定位因素便于归因，但用户已经授权整段重构时可整体重建，不把历史“一句prompt一次”当绝对限制。

最终报告保留实际差异：生视频不能保证像素锁定、群体人数可能近似、烧录文字遮罩是估计、原曲署名是源信息。避免把报告里的工程推测当导演的新设定。
