# 对话动画：短动作、曝光表、口型和完整人物分层

适用于保留原动画表演的对话片段。先按实际运动选路线，不把整镜一律交给生视频，也不把人物动画一律做成静图平移。本轮制作验证：短转身由 H3 提供完整人体中间状态；可靠的定格和口型用曝光表及局部合成；背景和相机从原片测量，通常比长段自由生成更容易控制。这个组合依赖可分离图层和用户授权，不能保证任意镜头都适用。

## 先做运动账本

逐镜记录源区间、绘稿变化帧、说话者、相机变换、背景变化、头/躯干/手/头发/饰品运动、前景遮挡。区分原片的真实切镜与生成跳变。保留精确有理数帧率，别把 24000/1001 当作精确 24。

| 原片实际内容 | 优先处理 | 改用其他路线的信号 |
|---|---|---|
| 整个人物绘稿定格 | 复用一张认可重绘，按原曝光长度保持 | 眨眼、发梢、胸肩或手在动 |
| 只有相机推拉/平移 | 同一人物及背景层按源片实测变换 | 多层视差，独立人物运动 |
| 确实只有嘴在变 | 同姿势重绘底稿 + 源口型事件表 + 局部嘴层 | 下巴、头、眼或头发一起变化 |
| 短转身、抬头、身体联动 | 原视频驱动的短 H3 动作，包含完整人物 | 模型改动作、加低头、改变衣服或保护角色 |
| 原片只有少量离散绘稿 | 每个真实状态重绘并复用原曝光表 | 独立重绘缺可信中间状态、身份不一致 |
| 复杂头发/布料运动 | H3 生成真实连续运动并验收 | 不能用手工扰动代替 |

全局 MAD 小不证明只有嘴在动。先抵消运镜，再比较眼、轮廓、发饰、肩和手的局部差值；缩略图会遗漏这些变化。不确定时保留全人物动画路线。

## 单帧保持清爽与身份

每轮重绘从原片对应帧直出，身份参考只提供发型、发色、瞳色和饰品。上一版可作判断参考，不反复把失败生成图当底图修脸；多轮编辑容易累积碎片、油纹和错误五官。用户指定永远直出时按此执行。

身份与表演分别约束：身份使用目标角色；眼睑开度、视线方向、眉毛、瞳孔的表演性形状、脸红、口型和头部角度照源片。普通身份瞳色不能压过惊讶时的简化瞳孔等原表演。不能把眯眼画成阴沉阴影，不能为露出饰品改头姿。

建立多角色身高关系时按同一地面、肩线和透视检查几张相邻构图；不能各张独立猜高矮。脸型、眼型、头饰要用正侧参考；不要为压低身高非等比缩短头部。只生成当前授权的服装政策。

## 短 H3 动作怎么取用

1. 向动作前后找可信的稳定状态，包含躯干、手臂和衣服，而不是只有头的 ROI。锚点姿态和参考职责写清；明确源片没做的低头、眨眼、额外说话等不可添加。
2. 根据后端可接受长度构建最小有效任务；模型序列可以比实际绘稿数长，保留源帧→模型帧映射。不要只为凑时长加入无关切镜。
3. 先交独立动作素材或自己验证全段，再选择与原片各姿势最接近的模型帧；模型动作峰值未必落在固定均匀采样位置。
4. 若原片确实只有三张转身绘稿，从连续生成中选对应姿势，复用原曝光表。不能因为用户说“三帧变化”就跳过源片分析，也不能凭空补成高帧率运动。
5. 不仅对齐头：检验肩、胸、腰、手臂和衣服联动。头动衣服冻结、两个头、颈部断开或瞬间转瘪均不通过。

动作已正确但后处理错时只修后处理，不重复付费生视频。短 H3 也无法可靠复刻时，报告偏差，不无限自动重跑。

## 完整人物分层

分层在用户允许且可可靠拆分时采用。人物层必须保留所有可见身体部位和衣服，背景独立，前景人物独立；头部单独粘贴不是完整人物替换。

- 对同一绘稿用一致的刚性平移/等比尺度；记录原相机轨迹和各层轨迹。别用几处头部点拟合非等比仿射，导致脸扁、躯干不动或角色漂移。
- 平移揭露原画框外区域时需要可信扩边；只应用在原画框之外，框内保留已通过像素，检查扩边与手臂完整性。
- 遮罩沿整个外轮廓及发束间隙检查，不只脸。自动抠图会漏手臂，也会把深色背景当头发/衣服。
- 透明人物边缘与底色的预乘 alpha 要一致。深色块、阶梯边、发丝虚影首先查 matte、旧人物残留、颜色污染和混合关系；单纯加大羽化可能制造光晕或双影。
- 检查头顶、耳后、下巴旁、领口、发梢、肩、手臂以及前景遮挡边缘。背景换亮以后，旧暗背景残块会更显眼，不能靠把背景压暗掩盖坏遮罩。
- 帧间复用稳定 matte；必要变化跟随真实姿势。逐帧独立抠图容易边缘闪烁。不能抹掉源片真实的头发/布料运动。

## 只有口型时的局部替换

先确认适用条件，按每个头部姿势建立干净底稿和嘴 ROI。源原片逐帧记录嘴形状态和曝光长度：闭口、微张、开口、横向等，不能依据音量随机开合。

侧脸嘴形常只有几像素高。先看源片原生裁切，再检查 4–8× 最近邻放大；嘴的中心、轮廓与侧脸边缘同样重要。不能把正面嘴强行贴到侧面，不能以模糊的大暗块代替口腔。

清理旧嘴时必须清除全部旧轮廓/暗块，检查其是否跨越脸部边界。较大的修补区可能需要分别恢复皮肤和背景；只对皮肤 inpaint 会留旧嘴、吞掉轮廓或形成不自然尖刺。每个姿势单独定标，小 ROI 不代表不需结构校验。

允许时可用源嘴层配合皮肤颜色匹配，但不要带入旧角色的眼、鼻或整张脸；检查轮廓、牙齿、舌头、开口大小、位置和时序。用户已经认可后半口型时，只改失败前段，验证后半像素不变。

## 三种校验同时做

1. **全局**：完整人物、前后景顺序、手臂缺失、尺寸、头身连接、镜头范围和动作一致性。
2. **局部放大**：脸、眼、嘴、头饰、发丝和 alpha 边缘；特别检查所有姿势变化及被指出的帧，不能只挑漂亮锚帧。
3. **时间与差值**：原速连续播放；逐帧比较源变化事件与生成变化事件；静止层差值、运动补偿后背景差值及嘴 ROI 外差值定位意外运动。修复段前一帧和后一帧一并检查。

差值指标是报警和定位证据，不是美术评分。不同身份不能要求与源片全像素相同；有损编码也不能做严格像素不变断言。无损修补可以且应验证指定区间外与最近认可底片一致。

审核原生底片通过后再超分。最终交付回读编码视频，原片/新版并排标源帧号；只检查拼图不能证明连续动作通过。报告检查范围和残留偏差，不承诺生成模型逐帧完全锁定。

## 资源与交接

一份当前选择表标明认可版本、帧区间、输入哈希和废弃原因。交接只给当前选中素材、对应帧号、口型/动作曝光及限制，不按 mtime 猜“最新版”。不擅自通知其他 agent。

清理前先找装配依赖：最新成片、源片、关键帧、采用的 H3 动作、可编辑人物/背景/遮罩、曝光表、口型表、脚本、日志需保留。大数组若只是已固化无损母版的重复缓存，可作为归档候选，但还需确认返修是否依赖它。

用户授权移到其他磁盘时，保留项目相对路径；预检源/目标绝对路径、空间和重名，按清单迁移，前后核对 SHA256，记录日志和恢复映射。不覆盖现有归档，不删原片或导演文件；移动成功释放本盘空间后再报告。路径和账号只放本地报告，不上传到公开 skill。
