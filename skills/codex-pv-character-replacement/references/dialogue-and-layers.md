# 对话、曝光与可分离图层

路线判断在 [SKILL.md](../SKILL.md)，验收统一见 [quality-control.md](quality-control.md)；这里仅说明制作方法。

## 源运动账本

逐人物记录源区间、相机变换、绘稿变化帧、嘴形、头/躯干/手/头发运动及遮挡进入/退出。背景气泡和光影另列，不能跟着人物曝光冻结。

先在静态背景估相机，再在人物稳定坐标中检测局部变化。用源片原生裁切确认事件：微张嘴、眼睑和手势会被全帧平均吞掉；遮挡或运镜也会产生伪事件。相位相关或光流失败时，检查内点、前后跟踪一致性、轨迹和实图，不直接采用算法最低分。

定格复用整张绘稿。纯平移先拼出镜头需要的完整画幅再重绘，按实测路径裁切播放；确认拼接无重影、画框覆盖充分，并保留源视线和表情。多层视差不强行套单一变换。

## 从 H3 取动作，再按原片曝光

1. 选择两侧可信状态，包含头、躯干、手和衣服。身体联动用完整人物连续生成，不能只驱动头部。源片没有的低头、转向、额外说话不能当作自然化接受。
2. 查看 raw 全过程，排除坏脸、双层头发、遮挡污染和错误动作。端点正确不足以证明中间正确；FL2VA 的实际输出端帧也可能不同于输入图。
3. 对每个源绘稿状态，按动作方向、头肩手位置和相对位移选择模型帧，保持单调顺序。**均匀抽帧只是候选，不是动作校准。** 点头不能用右转头代替；事件帧号对齐也不代表幅度对齐。
4. 将选中模型帧保持到下个真实源事件；两个人分别有事件时分别记录，不能让静止者随另一人一起动。图层能可靠分离时才分别回填，否则重做完整多人动作。
5. 保存源区间 → 模型索引 → 曝光长度。前后定格与中间画风不同时，可沿用认可 H3 的实际稳定帧，不继续混用独立生成的不同风格锚。保留独立运动的背景、前景和运镜。

## 完整人物与背景分层

仅在用户允许且层间可可靠分离时使用。人物层覆盖全部可见身体、衣服和配饰；头部贴片不是完整人物层。几何优先采用源相机和整层刚性平移/等比缩放，不用非等比仿射压扁头部或改脸型。

建立三类区域：人物真实轮廓及安全余量、确认空背景、需逐帧判断的遮挡/边界区。宽多边形保护区可能包含旧黑影和背景；全矩形裁切也可能带入不一致背景。二者只是制作遮罩，不是语义真值。

- 清理完整旧人物占据区域，检查旧发色、发饰、裙摆与运动尾迹；可信背景板不能含旧人残影。
- 外裁切覆盖全运动包络和滤波余量，重点看伸出的头饰、发丝、手及底边。框外需要可信扩边，不能黑色填充。
- 背景按原片时序连续播放；不可随人物换稿切气泡相位、墙壁位置或亮度。确实静态且无视差才复用稳定板；亮度插值不能代替运动背景重建。
- 稳定绘稿复用同一 matte；真实轮廓变化才更新。核对 alpha 预乘、旧底色污染和层级。羽化仅融合可信边缘，不能消除错位双影或保护区内部坏背景。
- 修背景只改实证为空的区域，羽化向安全区域内部收；供体需对齐且覆盖所需内容。坏影紧贴人物而无法分离时，重建人物及邻接背景，不把问题藏进保护区。
- 色彩参考同一照明下认可帧，分别检查皮肤、虹膜、背景及边界。不为遮拼贴全镜压暗，也不冻结真实光影。

## 只有口型变化的局部替换

先确认头、下巴、眼和头发都不换姿势，并确认用户允许。逐帧记录闭口、微张、开口等状态及曝光，不按音量随机开合。姿势或遮挡变化时改用对应完整绘稿。

嘴在头部局部坐标定位，再随人物/相机应用同一变换一次。轻微拉近时不能每帧用不稳定 bbox 重新贴嘴，也不能把运镜应用两次。用鼻、下巴、两侧脸颊核对中心、角度及离轮廓距离。

源嘴形状和时序用于表演参考，不带入原人物眼鼻。清除全部旧嘴暗块；修补区跨过侧脸时分别恢复皮肤和背景。牙齿、口腔、闭口线清晰度匹配当前小脸，局部过锐时调整该层采样，不能模糊全脸掩盖错位。

眼睛若只有瞳色错误，限制在确认的虹膜区，保留瞳孔、眼白、眼睑和高光；坏眼型、坏脸或刘海遮挡不能套固定眼贴片。身份眼型/配色与源视线/表情分别核对，见 [keyframes.md](keyframes.md)。

## 何时换方法

连续退回的双发层、脸颊尖刺、鼻嘴漂移、饰品裁掉或黑影，先查 raw、映射、matte、外裁切各层。同类问题再次出现，不继续扩大羽化、挪贴片或压亮度；回到干净完整绘稿或更长连续素材。raw 通过而合成失败，不重跑正确的 H3。

无法可靠分离或动作仍不符时，保留认可版本，明确剩余偏差与下一可行路线；不将技术产物标成用户验收通过。
