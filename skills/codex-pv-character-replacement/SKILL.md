# 单镜头锚定与 H3 连续制作

**一个镜头尽量只用一张 ImgGen 图片起步；后续从已检查的 H3 实际输出中选帧，作为下一段的首帧继续推理。** 只有切镜后出现新内容，或画面变化过大、H3 确实无法维持目标人物与构图时，才重新生图锚定。同源接续减少跳变，但仍需验证动作与接缝，不能承诺模型自动逐帧对齐。

一支 1 分钟试点返修约 32 轮，原因分三类：
- 约一半是开工前没定的规格：没有背面设定、颜色没有数值、小脸分辨率没定、参考图比例不对。
- 约三分之一是已有规则没执行：关键帧没和定稿比，没给用户审静帧就跑 H3。
- 约 15% 是模型做不到，却事后才发现。

第三段（1 分 11 秒）又返修 7 轮、约 17 个问题：约一半是**原片镜头结构判断错**（大画幅运镜、图层插入、一拍三换画、两镜共用背景都被当成"连续运动"或"静止画"），其余是链构造、提示词没带外观锁、第 4 关漏检，还有本 skill 两条规则互相冲突。

所以本 skill 的约束分三层：**开工前锁定、每镜四道关、禁止清单**。三层都是硬性要求，不是建议。

## 一、开工前锁定

用户确认一次；之后要改，重新确认。没锁定不开始批量生产。试点只锁定试点镜头涉及的内容。

模板、测量方法和数值依据见 [preproduction.md](references/preproduction.md)。

1. **角色规格书**，每个目标角色一页：
   - 正面、背面、侧面定稿。有背影或侧脸镜头时，背面和侧面必须有。
   - 头部特征清单：每件写形状、颜色，在角色自己的哪一侧。
   - 发色、瞳色、肤色的 HSV 实测值。
   - 小脸时眼和嘴怎么画，包括嘴里的颜色。
   - 线条粗细和画风简繁。
   - 服装约定。
2. **镜头测量表**，每个镜头一行，从原片量出：
   - 范围、在场角色（按帧区间，含入画出画）。
   - 构图：头宽、头部中心、裁切、看得到的部位。
   - 运镜路径，以及是不是多层运镜。
   - 表情：放大原片读出来。
   - 逐帧口型档位、眨眼。
   - 原画节奏和定格区间。
   - **结构分类（必填，按逐帧实测，不凭联系表判断）**，它直接决定做法。测法见 [preproduction.md](references/preproduction.md) 第 2 节：
     - **静止画**（全画面和每个小块的帧差都 <1.5）→ 定格一张关键帧，不跑 H3。
     - **几张静止画硬切**（整张画面连背景一起换）→ 每张一张关键帧。**只有背景也换了才算**；背景不动、只有人物换画的不是这一类。
     - **大画幅运镜**（逐帧相位相关累计位移，拼回整图残差 <4，甩镜也算）→ 拼原片画布，Codex 一次改整张，按实测位移逐帧裁切。
     - **图层插入/移动**（只有一块区域变，其余帧差 <1，如杂志弹入）→ 底图加单独图层（遮罩需用户同意）。
     - **人物不动、只有前景或道具在动**（如甩过画面的衣服）→ 人物用一张固定画面，前景从原片逐帧叠上来；底图取运动物完全离开后的干净帧。
     - **背景不动、人物按原画节奏换画**（一拍二/三）→ **一条 H3 链，再按原片节奏选帧**；不逐张出 Codex 图（每张都会重画背景和人物，背景闪、人物颤）。
     - **转场换画**（帧差尖峰，但前后是同一动作的延续，如跃起 → Q 版 → 落地）→ 一条 H3 链在换画处锁帧；被揉糊的帧从同一时刻的其他生成里选干净的。
     - **连续运动** → H3。
   - **相邻镜头是否共用背景（必查）**：量交界处背景区域的帧差，<2 就是同一镜，必须一条链做完，不能按两镜各起锚。
   - **结构判断给用户过目**：每镜一句"原片怎么做的、我们打算怎么做"，用户确认后再出关键帧。
   - H3 难点标记。标了的镜头事先和用户定做法。
   - 在场人物里每个配角（家人、路人）换不换、换成什么，**每一段开工都要问**，不能沿用上一段的默认。
3. **生产参数**：
   - 出图后端和必跑的去噪。GPT / Codex 图一律过 [gpt-anime-denoise](https://github.com/CXP-2024/gpt-anime-denoise)。
   - 按脸的大小定分辨率。
   - 段长、步数。
   - 设备分工和云机用量上限。

## 二、每个镜头四道关

| 关 | 做什么 | 不过怎么办 |
|---|---|---|
| 1. 参考图 | 定稿按本镜头比例截成 16:9（头宽、头部中心、后颈对齐原片），和原片叠加核对；脸小的镜头另给原片脸部放大定眼距 | 重截，不出图 |
| 2. 关键帧自检 | 出图、去噪后逐项对规格书：饰品形状和左右、HSV、头发长度和轮廓、人数、表情、裁切 | 有一项不过就重出，不进下一关 |
| 3. 用户审静帧 | 原片和关键帧并排发给用户 | 用户没通过不跑 H3 |
| 4. H3 后逐帧审 | 对测量表核对口型档位、眨眼、位置、颜色、抖动和接缝；**出五项指标**（背景稳定度、清晰度、接缝跳变、残影/多余人物、外观尺寸，见 [review-and-delivery.md](references/review-and-delivery.md)）；转场前后 ±8 帧全尺寸逐帧对照；交付时附本轮自检表，写清哪些量过、哪些没查 | 退回出错的那一层修；看得见的瑕疵修掉或交付时直接问用户，不写成"遗留"就交 |

## 三、禁止清单

每条都返修过。

- **不手动改成片颜色。** 颜色不对，改关键帧再重跑。
- **不把另一次生成的像素贴进来。** 局部复用只取同一条 take。整帧选用另一次生成里同一时刻的帧不算贴，但只用在原片换画处（前后本来就换画），连续动作中途换 take 会跳。
- **人物或镜头在动时，不贴局部（嘴、眼）。** 贴回只用于两者都静止，而且只换那几个像素。
- **原片定格（同一张原画）的帧不逐张重画。** 定格就沿用同一张。
- **两张不同的图不做像素叠化。** 跨镜头叠化用 H3 过渡段。**同一角色的两次渲染之间也不叠化**（会叠出双呆毛、双栏杆）；两条链的接缝只在原片换画处硬切。
- **同一个连续运镜只用一条链。** 不拆成各自起锚的单元；入画角色写进那一段的提示词。原片两镜共用一张背景时，也算同一条链。
- **不从目标角色还不在画面里的帧往后接她的入画。** 起点必须包含本单元所有出场的目标角色；入画就从含她的已审关键帧起链往回倒推，或在入画处锁一张经核对的帧。否则 H3 凭文字画她（实测头发长到盖满后背）。
- **固定机位的镜头只生成一次背景。** 不混用几张独立生成的图（每张都重画天空，换画处背景跳）；要姿势参考时，用 Codex 在同一张已审关键帧上只改姿势。
- **H3 段不短于约 12 个源帧。** 3–4 帧的段补齐到模型长度后 H3 几乎不动；短转场就跑一条穿过它的长段，再选需要的帧。
- **每段 H3 提示词带上规格书的外观锁**（发尾到哪、饰品始终长在头上、线条清晰），见 [continuous-h3.md](references/continuous-h3.md)。
- **按原片节奏选帧的后处理不能覆盖修好的帧。**
- **提示词：**
  - 不写否定词。
  - 不写画面里看不到的动作，也不写不在场的角色。
  - 位置、发型和身份要一起写。
- **项目约定禁用的后端，全项目不用。** 也不能拿它补一张"临时"图。
- **原片静止的镜头不跑 H3，原片里不动的人物不逐帧重画。** 前者会加出原作没有的动作，后者会让头发每帧都变。
- **长镜头每段的提示词只写这一段原片里发生的事。** 把整镜剧情写进每段，H3 会在 1.6 秒里乱演整个剧情。
- **只拍头发或道具的镜头，提示词不写人物描述。** 写了就会画出整张脸。
- **配角不凭文字描述设计。** 在原片里该角色清楚的一帧上直接替换，发型、视角照原作。
- **"左/右"一律写成画面上的位置（画面左侧、靠脸、后脑一侧），动手前先向用户复述确认。**
- **叠层合成的底图必须是干净帧。** 运动物（衣服、道具）还没完全出画的帧不能当底图；合成后逐帧对照原片。
- **H3 在跑时不干等。** 每隔几分钟拉回已完成的段检查，有问题当场追加任务；注意云机的 1 小时上限。

## 主流程

1. **接上正确版本。**
   - 确认原片、源帧率/PTS、镜头范围、角色映射、声音及去字要求。
   - 读取当前选帧清单、用户反馈，以及第一节的三张表。
   - 镜头号、源帧号、播放器帧号分开记录，范围用零基半开区间。
   - 局部返修以当前选用版本为底，保留范围外的资产。
2. **拆镜头、填测量表。**
   - 切镜候选必须对照画面确认，闪光和运镜会造成大量误报。
   - 无目标角色的舞台、空镜和路人镜头直接用原片。
   - 每镜按实测做结构分类（见第一节），并检查相邻镜头是否共用背景，先定好用定格、大画幅裁切、图层、叠层还是 H3。
   - **把每镜的结构判断给用户过目**（"原片怎么做的、我们打算怎么做"各一句），确认后再出关键帧。第三段 8 个结构错误，用户都是一眼看出原片做法；这一步只花用户几分钟。
   - 关键帧一次出齐、分组给用户审，全部通过后再整批跑 H3。
3. **画镜头起点（第 1、2 关）。**
   - 各自负责什么：原片同一帧定构图、动作、视线、比例、遮挡和光照；规格书和按比例截的定稿定身份与服装；认可样例定画风。
   - 匹配原片的简化程度。
4. **静帧审（第 3 关）。** 每个目标镜头定格在起点图上，和原片左右对比。人物、发型、构图通过后再跑 H3，这一步改图最便宜。
5. **生成短段。**
   - 原视频驱动动作和相机，首张编辑图是唯一的时间锚。
   - 每段不超过 39 帧，也尽量用满。不超过约 39 帧的镜头整镜一次跑完，可试多个 seed。
   - 先试跑几段确认方向，再放开全部队列。
   - 源片有风、动作或多层特效时，不用静图平移、局部扭曲或手动晃动代替。
6. **选实际帧继续。**
   - 在失败之前或当前短段结尾，选身份、姿态、曝光和遮挡都可靠的 H3 无损帧。记录它的模型索引和对应源帧，从同一源时刻继续。
   - 起点之前的部分用倒放段。
   - 接坏了就退回最后可信帧重跑，先不新增 ImgGen 锚。
7. **逐帧审片返修（第 4 关）。**
   - 每段都和原片逐帧对照，口型按测量表的档位核对。
   - 关键帧要改形状、姿态、表情或大小时重新生成；只改颜色或小饰品时，在合格图上编辑。
   - 视频帧的局部修补只按禁止清单允许的条件做；其他情况重跑 H3。
8. **合成后再检查。**
   - 链式段要拉直全局运动、处理接缝过渡、砍掉尾部静止再放慢，见 [pitfalls.md](references/pitfalls.md) 的"合成"。
   - 新资产写入逐帧台账，按原片节奏选帧（修过的帧加入保护集）。
   - 核对原片动作事件、全镜头和接缝；检查实际编码文件。
   - 局部修复要验证范围外的选帧或像素不变。
   - 交付后再更新"最新版本"入口，区分候选、选用和用户认可。

完整绘稿确实静止、或仅有整层相机运动时，可复用同一绘稿并复刻实测运镜，按原片保留静止曝光；多层运镜要分别量前景和背景的移动量。真正切镜可以建新锚；技术拆段不等于切镜。

**用户提出返修时：**
- 先归到最早出错的那一层：规格、参考图、提示词、关键帧、H3、合成，在那一层修。
- 把结论补进规格书或测量表，避免同类问题再来。
- 难点镜头组先单独交、一次收齐意见，不要每轮重渲整片。
