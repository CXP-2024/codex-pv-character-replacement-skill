# 单镜头锚定与 H3 连续制作

**一个镜头尽量只用一张 ImgGen 图片起步；后续从已检查的 H3 实际输出中选帧，作为下一段的首帧继续推理。** 只有切镜后出现新内容，或画面变化过大、H3 确实无法维持目标人物与构图时，才重新生图锚定。同源接续减少跳变，但仍需验证动作与接缝，不能承诺模型自动逐帧对齐。

## 主流程

1. **接上正确版本。** 确认原片、源帧率/PTS、镜头范围、角色映射、声音及去字要求；读取当前选帧清单与用户反馈。镜头号、源帧号、播放器帧号分开记录，范围采用零基半开区间。局部返修以当前选用版本为底，保留范围外资产。
2. **拆镜头并标角色。** 切镜候选必须对照画面确认，闪光和运镜会造成大量误报。标出每个镜头的出场角色；无目标角色的舞台、空镜和路人镜头直接用原片。
3. **画好镜头起点。** 原片同一帧决定构图、动作、视线、比例、遮挡和光照；目标参考决定身份与约定服装；认可样例决定画风。先检查整个人物，再启动 H3。匹配原片简化程度，不把细腻立绘画法带进平色 Q 版。
4. **先做静帧版给用户审。** 每个目标镜头定格在起点图上，与原片做左右对比。人物、发型和构图通过后再跑 H3；这一步改图最便宜。
5. **生成并检查短段。** 以原视频驱动动作与相机，首张编辑图作为唯一时间锚。每段不超过 39 帧；不超过约 39 帧的镜头整镜一次跑完，可试多个 seed。先试跑几段确认方向，再放开全部队列。检查真实输出中的身份、表演、背景和光效；首帧好看不代表整段可用。源片有风、动作或多层特效时，不用静图平移、局部扭曲或手动晃动代替。
6. **选实际帧继续。** 在失败之前或当前短段结尾，选择身份、姿态、曝光和遮挡均可靠的 H3 无损帧。记录其模型索引及对应源帧，从同一源时刻继续；起点之前的部分用倒放段。检查重叠，明确最终采用范围；接坏了就退回最后可信帧重跑，先不新增 ImgGen 锚。跨镜头叠化用 H3 过渡段接上前后镜头。
7. **逐段审片返修。** 每段都与原片逐帧对照，独唱和合唱镜头要逐帧核对口型。局部错误优先取同镜头实际帧的正确部分贴回；只改一处时用局部编辑，不整张重画。
8. **合成后再检查。** 链式段要拉直全局运动、接缝过渡、砍掉尾部静止再放慢，见 [pitfalls.md](references/pitfalls.md) 的“合成”。将新资产显式写入逐帧台账，按原片节奏选帧，核对原片动作事件、全镜头及接缝；检查实际编码文件。局部修复验证范围外无损选帧或像素不变。完成交付后再更新“最新版本”入口，区分候选、选用和用户认可。

完整绘稿确实静止或仅有整层相机运动时，可复用同一绘稿并复刻实测运镜；按原片保留静止曝光。真正切镜可建立新锚；技术拆段不等于切镜。不同镜头可按现有授权独立生产，同镜头的续段依赖前段检查结果。
