# PV 角色替换制作

目标是让新角色出演原来的演出。身份正确、单帧漂亮和视频可解码，都不等于转场与动作正确。

## 开始前

读用户当前要求、项目总纲、角色分配、文字方案、最新审核/退回记录、最近认可的输出及其帧台账。用户的新指示优先于旧文档；发现冲突只在工作记录中说明，不覆盖导演文件来消除冲突。没有受托修改的导演文件、已运行的模型环境保持只读。保留原片与生成历史，返修用新版本。

确认制作范围、母带、帧号基准、角色/服装政策、审核者和交付方式。用户改为自己串行审核时沿用这个决定，不恢复旧导演审批或并行队列。只询问实际阻塞项；不要把本案例的每阶段停点、20镜批次、角色名字、硬件上限变成所有项目的固定要求。

新片按 [workflow.md](references/workflow.md) 建立范围与样片；已有制作从当前失败环节继续，不重做已认可素材。

## 路线判断

| 内容 | 优先路线 | 必须核对 |
|---|---|---|
| 不换人的镜头 / 原有1080p图卡 | 原片直通或原尺寸图层 | 源版本与帧号完全对应 |
| 动作、复杂多层入退场、粒子遮挡 | 原视频驱动的 Ref2VA | 全段运动、切镜时机，而非仅端点 |
| 两端可信的短连续修复 | FL2VA 或等价首尾帧模型 | 中间状态和两侧接缝 |
| 同一静态CG的整层推拉旋转 | 同张重绘CG + 原片测得的几何 | 确实是同一图层，不能冻结独立动画 |
| 低帧率Q版/交替绘稿 | 原绘稿曝光表 + 对应重绘 | 中间描边、表情与出现次序 |
| 文字/Logo动画 | 干净动态画面 + 独立透明字层 | 几何、可见度、跨镜尾部 |
| 远景小脸 | 原片高分辨率局部驱动生成并回填 | 局部时间连续性与前景遮挡 |
| 对话中确实只有口型运动 | 原绘稿曝光 + 同姿势嘴层 | 嘴形、开闭时序、侧脸轮廓，ROI外无意外变化 |
| 少量绘稿构成的短转身 | 短H3完整人物动作 + 源曝光表 | 头、躯干、手臂和衣服一起对齐 |

对话片段先分清定格、运镜、口型和身体动作，再选路线。分层与局部替换需满足可可靠拆分和用户要求；头发/布料真实运动用视频生成，不添加手工扰动冒充原表演。详见 [dialogue-and-layers.md](references/dialogue-and-layers.md)。

## 制作中的关键约束

1. **编辑底图是原片目标帧。** 新人设只提供身份；原片画风锚提供线条与上色。把旧AI人设当底图往往锁死旧画风。详见 [keyframes.md](references/keyframes.md)。
2. **姿势对齐与动作复刻分开检查。** 头、眼、下巴、肩、手、角度、大小先对齐；用原片／新版／50%叠加检查。身份特征允许改变外轮廓，不要求新发型与旧发型像素重合。
3. **参考只放当前任务可见角色。** 无角色标题镜头不能放定妆照；多人板标清位置/身份，背景男性保留时明确其保护范围。不要让公共提示词凭空加人。
4. **时间轴可追溯。** 固定母带、零基半开区间、精确帧率或PTS，保存源帧→模型帧→原速输出→最终帧映射。禁止把并排预览右半裁作原生底片。
5. **GPU互斥。** 视频生成与超分共用一把锁；监测显存、温度、首步进度和总耗时。任务批准/撤回与文件哈希以提交前冻结快照为准。见 [h3-and-queue.md](references/h3-and-queue.md)。
6. **先定位再返修。** 比较原片、锚帧、原始H3、原速映射、合成、超分、最终编码，找到最早出错层。只重做受影响范围，并含足够上下文。见 [transitions.md](references/transitions.md)。
7. **超分修不了坏身份或坏小脸。** 原生画面通过后再超分；原生1080p镜头直通，文字在最终全时间线上后叠。见 [mastering.md](references/mastering.md)。
8. **技术通过与审片通过分离。** SSIM/copy_check/MAD是定位工具；白闪、擦除、相似目标发色可能导致误判或漏判。旧视觉退回不能被机器PASS撤销。

## 交付前

检查单帧结构、全段中间状态、前段→修复段→后段的原速连续性，特别是入退场方向、缩放速度、遮挡顺序、睁闭眼、饰品左右、Q版描边。审片需要时交左原片右新版并标源帧号；用户只要成片或独立彩蛋则交单画面。

记录实际采用版本、区间、输入哈希、原生/超分尺寸、耗时、显存测量口径、检查范围与未解决问题。完整解码并验证帧数/PTS、音轨和首尾；局部无损回填验证范围外像素不变。有损成片另做编码回读检查。不要把“没有报错”写成“完美复刻”。

技能调用不授权上传素材、创建公开仓库、购买模型或外发审核。仅在用户要求时执行相应外部动作。
