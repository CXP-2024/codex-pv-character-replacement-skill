# PV 角色替换制作

目标是让新角色出演原片的表演。身份、动作时序、合成结构、背景连续性分别验收；任何一个失败，都不能用平均差值低或视频可解码替代。

## 从哪里继续

先读当前请求、最新退回记录和选用台账，确定原片、最近认可底片、待修范围、帧号基准及角色参考。文件名含 final、mtime 最新、任务 complete 都不等于用户认可。沿用用户现有授权、串行/批量方式与服装要求，不恢复旧审核停点。返修另存版本，保留原片和可编辑依赖。

新项目按 [workflow.md](references/workflow.md) 建立身份和代表性样片；已有项目直接定位最早失败层：原片 → 锚帧 → H3 raw → 选帧/曝光 → 合成 → SR → 编码。**raw 已正确就修下游；合成反复失败就回到完整绘稿，别继续叠补丁。**

## 先分清什么在动

抵消源运镜后，分别确认各人物、嘴、背景、粒子与前景遮挡的变化，不能用全帧低差值判断全镜定格。

| 源片内容 | 首选方法 | 必须保留 |
|---|---|---|
| 完整绘稿不动 | 同一认可绘稿按原曝光复用 | 静止部件不额外晃动 |
| 同张CG纯平移/推拉 | 重建所需完整画幅，重绘一次，按实测相机播放 | 画幅覆盖、视线、原节奏 |
| 只有嘴动 | 同姿势底稿 + 源口型表；仅在用户允许时局部替换 | 微张/闭口、位置和局部清晰度 |
| 转身/点头/身体联动 | 短 H3 完整人物动作，按源事件单调选帧 | 方向、幅度、曝光长度、遮挡 |
| 少量离散绘稿/Q版 | 对应绘稿及原曝光表 | 线条、表情、形态的真实切换 |
| 多层转场/布料/粒子 | 源视频驱动的连续生成或可靠分层 | 各层独立轨迹与真实运动 |
| 不换人的原生画面 | 原片直通 | 原生细节和时间轴 |

动作与分层见 [dialogue-and-layers.md](references/dialogue-and-layers.md)；跨镜、溶解、跑步和相机见 [transitions.md](references/transitions.md)。原片直出与身份锚职责见 [keyframes.md](references/keyframes.md)。

## 返修闭环

1. **固定问题与基准。** 将用户时间码映射到实际版本的源帧/输出帧；加速、裁切和零/一基编号不能混用。找完整失败区间及两侧可信状态，不漏中间帧，也不越界覆盖认可动画。
2. **验证一个可归因的修法。** 保留 raw、选帧表、层和遮罩。前中后统一画风；中段 H3 已认可且两侧人物确实定格时，可取同一 H3 的实际稳定帧复用，不把旧风格端点接回去。
3. **检查全部变化帧与接缝。** 按 [quality-control.md](references/quality-control.md) 查看完整构图、放大细节、空间差值及原速连续性。遮罩本身也要验，不用同一错误遮罩定义修补区和全部检查区。
4. **据失败层迭代。** 调阈值、加羽化、压暗背景、全局模糊或换 seed 不能代替根因修复。同类结构错误再次出现时重新定位；无法可靠分离或配准，就停止该局部拼贴路线，改用可信背景板、完整绘稿或连续动作素材。沿用户授权继续，不虚报通过。
5. **回填并回读。** 从当前选用母版装配，仅覆盖计划范围；原生通过后做需要的 SR。核对无损范围外像素、解码、帧数/PTS、音轨与字幕；技术检查、人工观察、用户认可分别记录。
