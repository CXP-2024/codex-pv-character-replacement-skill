# Codex PV Character Replacement Skill

保留原片画风、分镜、动作和光效的动画角色替换方法，也适用于改动桥段含义的二创改编。核心是：**一个镜头一张 ImgGen 起点图，160 帧以内整镜一次跑完，除起点外不放独立画的引导帧；内容出错先加锁定句，再用"改帧"（取 H3 自己那一刻的帧只改一处，放回原时刻）。** 超过约 160 帧才分块，后一块从已检查的 H3 实际输出接续；仅在切镜出现新内容或 H3 确实失效时重新锚定。仍需逐帧审，不保证自动逐帧还原。

约束分三层，都是硬性要求：
- **开工前锁定**：角色规格书、镜头测量表、生产参数；改编片另加改编表，改动剧情要用户先同意。
- **每镜四道关**：参考图按镜头比例截、关键帧自检、用户审静帧、H3 后逐帧审。
- **禁止清单**。

这三层来自一支 1 分钟试点约 32 轮返修的复盘：约一半返修是开工前没定的规格，约三分之一是已有规则没执行。

第三段（1 分 11 秒）又返修 7 轮，约一半是**原片镜头结构判断错**：大画幅运镜、图层插入、背景不动的一拍三、两镜共用一张背景、转场换画，都被硬套成"连续运动"或"静止画"。因此测量表的分类扩成 8 类，并要求每镜的结构判断先给用户过目；H3 后逐帧审加了五项数值指标。

一部 107 秒的二创短片（替换加改编，交付 9 版）看片后提出 20 个问题：
- 9 个是**改编没设计好**：照搬原片桥段的含义、画面读不出、谁对谁做什么弄反了。
- 3 个出在 H3 做法，其中 2 个是这个 skill 当时的规则造成的（39 帧分段加中途关键帧，静止段用静帧）。
- 其余是开工前没定的事：原片不完整、BGM、限制规则的范围。

因此做了这些改动：
- 加了改编表：设计时优先"动作不变、只改结果"，实测 7 镜一次通过；动作方向和原片相反的 5 镜，只改提示词全部失败。
- 改成整镜一次跑、除起点外不放独立引导帧。
- 有人物的静止段先连续跑，不直接用静帧。
- 第 4 关从五项指标扩到八项。

一支 69 秒的十人换角 MAD（交付 7 版）：关键帧被打回 18 次，六成是没放大原片就动笔；看成片后的问题大头出在"是不是同一张画"没测：
- 同一张画的数码缩放被当成切镜，两边各起一张关键帧，画面在缩放处突变；
- 切换处一两帧的单独画面（甩进来的特写、过肩镜头）被直接硬切；
- 保留原片的范围边界偏了 1–5 帧，漏进了原片人物；
- 起点放在镜头中间、前向倒放各一条时，倒放链穿过单向拉远，运镜变成了来回。

因此做了这些改动：
- 切镜点改用特征匹配判断"是不是同一张画"，开工时列出每个切换点 ±4 帧的单帧插入和整帧效果（闪白、黑白闪、淡出淡入、甩镜模糊）。
- 单向拉远、平移的镜头起点放在近的一端，只跑一条前向链；一张原画中途缩放也只用一张关键帧。
- 交付前每一版都跑全片检查：原片帧审计、全片每 4 帧对照、逐镜运镜方向对比。

## 安装与使用

将 `skills/codex-pv-character-replacement` 复制到 `~/.codex/skills/`；更新前保留自己的本地修改。

GPT / Codex 出的二次元关键帧带鱼鳞纹，要配合去噪 skill [gpt-anime-denoise](https://github.com/CXP-2024/gpt-anime-denoise) 使用：把那个仓库也放进 skills 目录，每张出图都先去噪再进 H3。

```text
使用 $codex-pv-character-replacement，继续当前 PV 角色替换。
沿用当前选用版本；先锁定角色规格书和镜头测量表，关键帧先给我审静帧；每镜头一张生图起点，以实际 H3 输出续跑，检查与原片的动作和接缝。
```

静态图不强制跑视频模型；已有明确的离散绘稿工作流按用户约定执行。此 skill 的默认动态制作方法是源视频驱动的 H3 连续链。

## 辅助工具

`pv_manifest.py` 使用 Python 标准库，提供均匀映射候选、hash 冻结/复核和台账检查；不会提交 GPU 或认定美术通过。`review_board.py` 依赖 Pillow，生成原片/新版/叠加审阅图。`cut_audit.py` 测每个分镜点前后是不是同一张画、列出成片多出来的跳变、出原片对照联系图；`camtrack.py` 逐帧量原片和成片的缩放与位移方向。这两个依赖 numpy、opencv-python、Pillow 和 ffmpeg（不在 PATH 上时用 `--ffmpeg` 或环境变量 `FFMPEG` 指定）。现有脚本接口保留，不要求生产项目迁移格式。

```sh
python -m unittest discover -s tests -v
```

需自行提供图像生成工具与 H3 后端。仓库不包含模型、原片、角色图、字体、音轨、凭据或本机服务配置。文档与脚本采用 [MIT](LICENSE)，第三方素材各有其许可。
